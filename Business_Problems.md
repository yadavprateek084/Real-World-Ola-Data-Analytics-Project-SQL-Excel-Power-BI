# 🚖 Ola Ride Booking Analytics

> An end-to-end Data Analytics project focused on analyzing ride booking operations using **SQL** and **Power BI** to generate actionable business insights.

---

## 📌 Project Overview

The ride-booking industry generates massive volumes of real-time operational and customer data every day. This project aims to analyze booking patterns, customer behavior, ride cancellations, revenue trends, and service quality metrics to help improve overall business performance.

Using **SQL** for data analysis and **Power BI** for dashboard visualization, this project transforms raw ride-booking data into meaningful insights for strategic decision-making.

---

# 🎯 Business Objectives

- Analyze ride booking trends and operational performance
- Monitor successful and cancelled rides
- Identify top-performing vehicle categories
- Track customer and driver satisfaction ratings
- Analyze revenue across payment methods
- Understand ride cancellation reasons
- Build interactive dashboards for stakeholders

---

# 📊 SQL Analysis Questions

### 1. Retrieve all successful bookings

### 2. Find the average ride distance for each vehicle type

### 3. Get the total number of cancelled rides by customers

### 4. List the top 5 customers who booked the highest number of rides

### 5. Get the number of rides cancelled by drivers due to personal and car-related issues

### 6. Find the maximum and minimum driver ratings for Prime Sedan bookings

### 7. Retrieve all rides where payment was made using UPI

### 8. Find the average customer rating per vehicle type

### 9. Calculate the total booking value of rides completed successfully

### 10. List all incomplete rides along with the reason

# 📈 Power BI Dashboard Requirements

The dashboard provides interactive insights into ride-booking operations through the following KPIs and visualizations:

| Dashboard Visualization | Description |

| Average Customer Ratings by Vehicle Type | Analyze customer satisfaction |
| Cancelled Ride Reasons | Understand cancellation patterns |
| Revenue by Payment Method | Track payment-based revenue |
| Top 5 Customers by Total Booking Value | Identify valuable customers |
| Ride Distance Distribution Per Day | Analyze travel behavior |
| Driver Ratings Distribution | Monitor driver performance |
